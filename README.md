# Обход точек ХЧ

Простая версия веб-приложения.

## Запуск без компьютера

Файлы подготовлены как устанавливаемое PWA, но приложение пока не опубликовано. Для автономного запуска на телефоне его нужно один раз разместить на HTTPS-хостинге и открыть выданную ссылку. После этого на iPhone откройте её в Safari и выберите «Поделиться → На экран Домой»; на Android — «Установить приложение» в меню браузера. После первой загрузки приложение сможет открываться офлайн.

Данные обходов сохраняются в браузере телефона и автоматически не синхронизируются с другими устройствами.

## Использование

1. Введите имя проверяющего и выберите точку.
2. Введите имя проверяющего и выберите точку.
3. Выставляйте оценки 2, 1 или 0; при необходимости добавляйте комментарий и фото.
4. В конце откройте результат, назначьте ответственных по нулевым пунктам и сохраните обход.

Черновики хранятся локально в браузере на этом устройстве. Сводку можно скопировать кнопкой в итогах обхода.

## Примечание по баллам

В чек-листе 57 оцениваемых пунктов, то есть максимум составляет 114 баллов. В исходном документе указано 118: максимумы разделов 2 и 7 завышены на 2 балла каждый. Приложение считает процент от 114, исходя из фактического числа пунктов.
