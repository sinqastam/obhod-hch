# Публикация «Обход ХЧ» в GitHub Pages

Файлы приложения и GitHub Actions готовы для статического HTTPS-хостинга. После публикации Pages выдаст постоянную ссылку вида `https://<аккаунт>.github.io/<репозиторий>/`.

## Что нужно

- В настройках репозитория открыть **Pages** и выбрать источник **GitHub Actions**.
- Каждый push в ветку `main` запускает workflow `.github/workflows/pages.yml` и публикует файлы сайта.

GitHub Pages публикует сайт публично. Результаты обходов остаются в локальном хранилище браузера конкретного телефона; сервер их не получает.

## Установка на телефон

- **iPhone:** открыть опубликованную ссылку в Safari → «Поделиться» → «На экран Домой».
- **Android:** открыть ссылку в Chrome → меню → «Установить приложение» или «Добавить на главный экран».

После первой загрузки приложение доступно офлайн, пока не очищены данные сайта в браузере.
